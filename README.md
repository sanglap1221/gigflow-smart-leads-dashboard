# GigFlow Smart Leads Dashboard

A Full Stack MERN Lead Management Dashboard built with:
- React + TypeScript
- Node.js + Express + TypeScript
- MongoDB
- JWT Authentication
- RBAC
- Advanced Filtering
- CSV Export
- Docker

## Features
- Authentication
- Leads CRUD
- Search & Filtering
- Pagination
- Protected Routes
- Role-based Access
- Docker Setup
- Responsive UI
